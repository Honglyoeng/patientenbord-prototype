# Patiëntenbord Prototype

Interactive prototype of a patient information whiteboard for a hospital room. Tap the containers to open trays of magnets, place them on the board, and fill in fields with the marker. Switch between Dutch (NL) and English (EN) on the table.

**Live site:** https://honglyoeng.github.io/patientenbord-prototype/

It's a single static page (`index.html`) with no build step, so it can be hosted anywhere that serves static files (GitHub Pages, Vercel, Netlify).
